# PBO Pseudo-Boolean Optimization
This project implements multiple algorithms (such as 1+1 EA, RLS, MMAS, MMAS*, GA, and ACO) to solve a variety of Pseudo-Boolean Optimiza-tion problems.
It is highly modular and customisable.

## How to use
1. Navigate to the `code` folder.
2. Navigate to the `main.py` file to run the 1+1 EA, RLS, or ACO functions.
3. Alternatively navigate to the `mainGA.py` file to run the GA function.
4. Configure parameters within `main.py`:
   - Set func (ea11 or RLS)
   - Adjust parameters as you like.
   
5. Configure parameters within `mainGA.py`:
   - Adjust parameters as you like.
6. Run script with `python main.py` and `python mainGA.py`
